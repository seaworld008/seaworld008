### ☁️ 天空AI · 一个入口接入常用 AI 工具

[天空AI](https://api.skyai.icu) 是我们的 AI API 中转站：用一个兼容 OpenAI / Anthropic 的入口，把 Codex、Claude Code、OpenAI SDK 和其他常用工具接到已配置的模型服务。先阅读[使用指南](https://api.skyai.icu/guide/)，再注册、创建密钥并按实际用途设置限额。

> 天空AI是独立运营的接口接入与用量管理服务，与模型厂商保持独立关系。模型、协议、价格和可用性以服务页面与实际配置为准。
